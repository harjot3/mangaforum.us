# MangaForum.us

A manga catalog and community being built around chapter-level reading progress and spoiler-aware discussion. Spring Boot owns the API and business logic; Next.js renders the application.

Development proceeds vertically. Phase 1 establishes the read-only catalog, relational model, manga pages and chapter listings. Accounts and reading progress interactions follow in Phase 2; discussion and backend-enforced spoiler filtering follow in Phases 3 and 4.
